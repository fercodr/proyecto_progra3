# EntreFunciones

Proyecto de Programación 3 con backend Java y frontend Blazor C#.

- `Backend/pom.xml`: proyecto Maven y módulo `entrefunciones-rest` desplegable como WAR.
- `Frontend/EntreFunciones/EntreFunciones.csproj`: aplicación .NET 10.
- `Backend/sql`: esquema, procedimientos canónicos, migración y datos opcionales.
- `docs/LAB11`: informe corregido, diagramas editables, configuración, cambios y verificación.
- `docs/entregas/LAB06`: material histórico de esa entrega.

Para integrar esta entrega, seguir `docs/LAB11/INTEGRACION.md`. Las correcciones cubren las reglas de programación, reserva y pago; el resto de los módulos conserva el avance del equipo.
